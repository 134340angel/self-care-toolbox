# Self-care-tools

一组简单的生活小工具，给需要精神状态管理的人。


## 🌙 现有工具

| 工具 | 说明 |
|---|---|
| [睡眠时间轴](./index.html) | 记录每晚的入睡、起床时间、睡眠质量和梦，按日 / 周 / 月 / 年查看作息规律，比较睡眠视图 |

更多小工具会慢慢加上。

## 🔒 关于隐私

- **默认情况下，你的数据只保存在你自己的浏览器里**，不会上传到任何地方。
- **多端同步是可选的。** 开启后，数据会先在你的设备上用同步码加密，再上传到服务器。服务器上只有看不懂的密文，开发者也看不到内容。同步码只保存在你的设备上，忘了就无法找回云端的数据。
- 不需要账号，不收集任何个人信息。
- 没有开启同步时，**换手机、换浏览器或清除浏览器数据后，记录会消失**。请定期点页面上的「复制全部数据」备份，或者开启多端同步。
- 页面里的「AI 总结」不会自动发送数据。它只是帮你生成一段提示词，可以复制给AI。

## ⚠️ 请注意

这些工具只用来**自我记录和整理生活**，不是医疗工具，不能代替医生、心理咨询师或任何专业治疗。

如果你正在服药或接受治疗，请继续听从医生的建议。记录下来的数据，也可以在看诊时拿给医生参考。
